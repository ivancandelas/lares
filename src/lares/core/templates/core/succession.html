Cómo funciona

  1. Se cuentan los días sin que entre nadie que administre el hogar. {% if ultimo %}El último fue el {{ ultimo|date:"j \d\e F \d\e Y"|lower }}.{% endif %}
  2. Al llegar al plazo te avisamos a ti, no al contacto. Todavía no hay nada que entregar y no hace falta preocupar a nadie.
  3. Si sigue el silencio pasada la ventana de gracia, se libera el paquete y le llega el enlace.
  4. Si vuelves a entrar, el enlace deja de funcionar. Quien vuelve está vivo.

El enlace es de solo lectura y cada apertura queda contada. Los documentos marcados como privados o secretos se nombran, pero no se entregan.
